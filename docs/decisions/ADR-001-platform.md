# ADR-001 · 云游戏平台选型

- **状态**：🟡 Proposed（待决策）
- **日期**：2026-05-12
- **决策者**：Max
- **影响范围**：整个 CV 层（区域坐标、模板库、动画时序）

## 背景

Mayou 通过云游戏窗口截屏来识别麻将牌局。**云游戏平台一旦选定，几乎不能换**——区域坐标、模板库、识别参数全部绑定单一平台。换平台 = 整个 CV 层重做。

转转麻将主要在以下平台可玩：

- 黄金岛（PC 端原生客户端，转转麻将的"祖庭"）
- 腾讯欢乐麻将（PC 端、需要找到转转麻将房间）
- 各家云游戏平台运营的麻将类应用

## 候选

### A. 黄金岛 PC 客户端（不走云游戏）

**优点**：
- 转转麻将规则最正宗
- 原生客户端，画面稳定无压缩失真
- 自带回放功能可作为测试数据来源

**缺点**：
- 不是云游戏，违反"云游戏方案降低风险"的初衷
- 反检测可能更严（原生客户端能监测进程）
- Max 用户量级有限，可能不在欢乐场范围

### B. 网易云游戏 + 某麻将 App

**优点**：
- 真正的云游戏，App 端零检测可能性
- 网易云游戏稳定性较好

**缺点**：
- 需确认是否上架转转麻将相关 App
- 视频流压缩，识别难度略高
- 有时段限制（免费用户）

### C. 腾讯先锋云游戏 + 某麻将 App

**优点**：
- 大厂稳定
- 设备覆盖好

**缺点**：
- 麻将类游戏可能较少
- 同上的视频流压缩问题

### D. 咪咕快游

**优点**：
- 中国移动旗下，长期免费时段较多

**缺点**：
- 游戏库偏向 3A，棋牌类较少

## 选型评估维度

| 维度 | 权重 | 说明 |
|---|---|---|
| 是否支持转转麻将（欢乐场） | 必要 | 不支持直接淘汰 |
| 画面稳定性 | 高 | 影响识别准确率 |
| 截屏权限 | 高 | 反截屏会让方案完全失效 |
| 延迟 | 中 | 影响 Max 操作体验，不影响识别 |
| 长期可用性 | 高 | 不希望几个月后下架 |
| 免费时长 | 中 | 2 小时/周需求，多数都够 |
