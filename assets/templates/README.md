# 模板库

> 牌面识别用的模板图像。
> **不要手工编辑** —— 用 `tools/template_annotator.py` 采集。

## 结构

```
assets/templates/
├── index.json              # 总索引（程序生成）
├── <platform>/             # 每个平台一份模板
│   ├── tiles/
│   │   ├── lower_1/        # 小写「一」
│   │   ├── lower_2/        # 小写「二」（红色）
│   │   ├── ...
│   │   ├── lower_10/       # 小写「十」（红色）
│   │   ├── upper_1/        # 大写「壹」
│   │   ├── ...
│   │   ├── upper_10/       # 大写「拾」（红色）
│   │   └── back/           # 背面
│   └── markers/
│       ├── peng/           # 碰
│       ├── wei/            # 偎
│       ├── ti/             # 提
│       ├── pao/            # 跑
│       ├── chi_jvhua/      # 吃·一句话
│       ├── chi_jiao/       # 吃·绞牌
│       └── baojing/        # 五福报警
└── _unrecognized/          # 识别置信度低的图像，待补模板
```

## 株洲碰胡牌型 21 类

株洲碰胡是**湖南字牌**（不是麻将），共 80 张：

- 10 种小写（lower_1 ~ lower_10）：「一二三四五六七八九十」
- 10 种大写（upper_1 ~ upper_10）：「壹贰叁肆伍陆柒捌玖拾」
- 1 种背面（back）

**红色牌**：小二、小七、小十、大贰、大柒、大拾。识别时颜色（红/黑）可作为字面识别的二级验证特征。

详见 [../../docs/07-zhuzhou-pengHu-rules.md](../../docs/07-zhuzhou-pengHu-rules.md)。

## 采集目标

每种牌至少 5 张样本，覆盖云手机视频流可能的轻微色彩偏移和动画稳定后的视觉变体。
