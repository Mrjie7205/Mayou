# ADR-003 · 目标水平升级：中等人类 → 顶尖人类

- **状态**：✅ Accepted
- **日期**：2026-05-13
- **决策者**：Max
- **影响范围**：PRD MVP-2 验收标准、引擎层架构、ROADMAP 周期、所有 Sprint 后期内容
- **关系**：修订 PRD §4 MVP-2 验收。不取代任何旧 ADR。

## 背景

PRD 初稿把 MVP-2 验收设为「在闲逸欢乐豆房间对线，Max 主观感觉中等水平人类玩家」。原因是把 Mayou 当成 2 小时/周练手项目，目标不高。

Sprint 1 实战准备阶段，Max 把算法详解发给独立 AI（Gemini）做两轮交叉评审。第一轮指出 6 项防守逻辑硬伤（已纳入 Batch 1 修复）；第二轮给出可达到「顶尖人类水平」的 5 条技术路径：

1. 废弃静态加权，重构为绝对期望收益 (Net EV)
2. 引入贝叶斯/启发式对手信念状态
3. MC 引擎升级（剔除纯随机弃牌）
4. 增加破坏性防守 + 反事实诱导
5. 加速离线沙盒自对弈 + 参数寻优

Claude 评估后建议：4 条采纳，1 条（诱导防守）暂不做（涉及 minimax 多层博弈，超出当前架构）。其中：

- 「贝叶斯信念状态」上**简化版启发式**（3 档状态：Maybe/Unlikely/Impossible），不上真贝叶斯（无对局数据 + 工程量 1000+ 行 + 性能跌到 200ms+）
- 「破坏性防守」只做**卡位**（扣死关键牌），不做诱导（造安全假象）

## 决策

**Mayou MVP-2 的最终目标从「中等人类水平」升级为「顶尖人类水平」**。

具体定义：
- 在闲逸欢乐豆房间对线，**稳定击败中等水平人类玩家**
- 对**顶尖人类玩家有竞争力**（不要求胜率超过他们，但建议质量接近）
- 引擎依然遵循 CLAUDE.md 硬约束（无神经网络、无大模型、纯经典算法）

## 路径

分三波迭代，逐步逼近：

### 🔴 Wave 1（短期，立刻做）

1. **简化版 EV 公式**：`combined = win_prob × my_score - max_opp_threat × loss_score`，替代当前线性加权 `α × attack + β × defense`
2. **对手向听粗估**：按副露次数 + 弃牌量反推 ≤1 / ≤2 / ≥3 三档
3. **MC 启发式弃牌**：`_fast_eval_discard`（优先打孤张、不打高危生张）替换 `random_choice`
4. **卡位防守**：对手 peng_count ≥ 3（接近五福）时，对所有未现身字号高警戒

### 🟡 Wave 2（中期）

5. **shanten 真 DP + 数组化**（原 Batch 2 搁置项）：把 Tile 对象换成 20 维数组 + lru_cache 跑精确 DP
6. **简化版持有概率向量**：每对手 × 20 字号的 3 档状态（Maybe/Unlikely/Impossible），启发式更新（不上真贝叶斯）
7. **EV 升级**：接入持有概率 + 对手向听后更精准

### 🟢 Wave 3（长期，达到顶尖水平的核武器）

8. **`scripts/bench_engine.py` 离线自对弈框架**：两引擎实例对打 + 胜率统计
9. **参数 grid search**：暴力枚举关键超参（α/β/danger 权重/MC 次数等）
10. **遗传算法 / 贝叶斯优化**：自动调参，让 V1.x 在沙盒里互打逼近最优
11. **基于自对弈数据的真贝叶斯先验**：等 bench_engine 产出上百万局日志后，从统计学得出真实先验，再替换 Wave 2 的启发式

## 不做（明确划线）

- **诱导防守**（造安全假象）：等价 minimax 多层博弈，状态树爆炸，超出当前架构
- **神经网络 / RL / LLM 推断**：CLAUDE.md 硬约束 4 不变
- **自动出牌**：CLAUDE.md 硬约束 + PRD §2.2 不变

## 后果

### 周期

预计 MVP-2 完成时间从 **38-44 周** 延长至 **60-80 周**。按 Max 2 小时/周节奏滑动，实际可能更长。

Max 接受加长周期换更高目标——本项目是个人技术探索，无 deadline 压力。「探索无神经网络下的深度博弈算法边界」本身是项目核心乐趣。

### 引擎复杂度

- 代码量：约 2850 行 → 预计 5000-6000 行（不含 bench_engine）
- 单局推荐计算时间：当前 80ms → 可能涨到 120-150ms（接 Wave 2 后），仍在 200ms 端到端预算内

### 风险

- **过度工程**：每个 Wave 引入的复杂度可能让 Bug 难以排查。每个 Wave 完成后强制实战 ≥ 20 局再进下一 Wave
- **参数空间爆炸**：手调 magic number 数量从当前 ~10 涨到可能 50+。Wave 3 离线寻优是唯一解
- **离线对弈的"局部最优陷阱"**：引擎对自身可能收敛到次优解。Wave 3 必须设计多版本互打 + 随机扰动机制

## 重新评估触发条件

- Wave 1 完成后 Max 实战 50 局，若胜率 < 50%（对中等人类）→ 修方向
- Wave 2 完成后 Max 实战 100 局，若主观感觉未达"接近顶尖" → 重审 Wave 3 设计
- 任何 Wave 实施过程中发现工程量超估 2x → 暂停并讨论是否回退目标

> 「不接神经网络也能做到人类巅峰水平」——这是本项目最有意思的赌注。
