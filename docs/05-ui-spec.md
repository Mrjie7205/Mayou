# 05 · UI 规格

> PySide6 主控台窗口。左半适配区（指引拖云手机窗口对齐）+ 右半信息栏（记牌器 / 出牌指引 / 牌局分析）。
> "够用、能调试、能复盘"，不追求美观。

## 形态总览

Mayou 是一个**主控台风格的常规窗口**（不是悬浮窗），典型布局：

- 屏幕右半边：Mayou 主窗口
- 屏幕左半边：红手指 PC 客户端（云手机里跑闲逸 → 株洲碰胡）
- Max 自己手动出牌（在云手机里点），Mayou 给出建议

**为什么不做悬浮窗**：本项目识别区域大、信息栏复杂，悬浮在云手机窗口边缘空间太小。主控台更适合。

## 左半边：屏幕区域适配

**核心交互**：Max 拖红手指窗口对齐 Mayou 给出的目标位置/大小，让识别能精确截到牌桌。

### 适配流程

1. Mayou 启动 → 检测到没有保存过的适配 → 自动进入「适配模式」
2. 适配区显示一个**虚线参考框**，标注「红手指窗口应该在屏幕左半边、宽 1280px、高 720px」（具体数值 Sprint 0 实测后定）
3. Max 把红手指 PC 客户端拖到那个位置、调整到那个大小
4. 点「抓帧预览」→ Mayou 截图整屏左半区域 → 缩略图显示在适配区中央
5. Mayou 在缩略图上叠加各区域识别框（手牌区、弃牌区、副露区、报警指示位等），用不同颜色标
6. Max 肉眼判断：识别框是不是套住对应的牌区？
7. 套住 → 点「保存适配」→ 写入 `assets/configs/redfinger.json`
8. 没套住 → Max 微调红手指窗口大小/位置，回到步骤 4

### 适配模式之外

- 启动时如果检测到 `redfinger.json` 已存在且配置完整 → 跳过适配，直接进入运行模式
- 运行模式下「屏幕区域适配」区显示**当前截到的实时帧**（5fps 刷新），叠加识别结果
- 想重新适配 → 设置里有「重置适配配置」按钮

### 为什么这么设计

- **不依赖窗口标题/进程检测**：红手指改版后窗口标题可能变，但屏幕坐标稳定
- **不依赖 Windows API 嵌入第三方进程**：完全靠截图，零侵入
- **Max 看得见识别框对不对**：所见即所得，问题排查直观

## 右半边：信息栏

四个区块从上到下：出牌指引、记牌器、牌局分析、事件日志。每个可折叠。

### 出牌指引

**显示 2 张**：最推荐 + 一张备选。

```
┌─ 出牌指引 ──────────────┐
│ #1 推荐: 小七 (红)      │
│   进攻 0.62              │
│     └ 打后 1 向听        │
│     └ 胡牌率 18%          │
│     └ 期望积分 18 分      │
│   防守 0.81              │
│     └ 上家危险 5%        │
│     └ 对家危险 32%       │
│     └ 下家危险 12%       │
│   综合 0.71              │
│ ─────────────────────── │
│ #2 备选: 大叁           │
│   综合 0.63              │
│   (悬停看分项)           │
└─────────────────────────┘
```

未来如果 Max 觉得 2 张不够，可以扩到「显示前 3」或「全部 14 张都标分」——通过设置切换，不改主代码。

### 记牌器

20 种字 + 红黑分组 + 剩余张数。布局示意：

```
┌─ 记牌器 ────────────────┐
│         小写              │
│ 一 4  二 2🔴  三 4  四 4 │
│ 五 4  六 4  七 1🔴  八 4 │
│ 九 4  十 3🔴             │
│         大写              │
│ 壹 4  贰 0🔴  叁 3  肆 4 │
│ 伍 4  陆 4  柒 4🔴  捌 4 │
│ 玖 4  拾 2🔴             │
└─────────────────────────┘
```

- 数字 = 剩余张数（含他人手里 + 牌墩，不含已弃和已副露的）
- 🔴 标红色牌
- 颜色提示：剩 0 字号 = 灰色弱化，剩 1 字号 = 黄色突出（这张是孤张候选）

### 牌局分析

显示「自己」+「另外 3 家」的关键信息：

```
┌─ 牌局分析 ──────────────┐
│ 自己 1 向听              │
│   等待: 小七 大柒        │
│   剩余等待张: 8 张        │
│   胡概率 23% / 期望 18 分│
│ ─────────────────────── │
│ 上家 🟢 安全 (现物多)    │
│ 对家 🟡 中危 (听双碰?)   │
│   高危: 小5 大伍          │
│ 下家 🔴 五福报警!         │
│   仅听 五福或跑胡         │
│   高危: 小七 大柒         │
└─────────────────────────┘
```

颜色阈值（可调）：
- 🟢 整体危险度 < 0.2
- 🟡 0.2 - 0.5
- 🔴 > 0.5 或 触发五福报警

### 事件日志

最近 20 条，最新在上。格式：`[时间] 家位 动作 牌`

```
[15:23:45] 对家 打 小5
[15:23:42] 下家 偎 大壹 (强制)
[15:23:40] 上家 摸 (未示众)
[15:23:38] 自己 打 大伍
[15:23:33] [manual] 修正: 对家碰组改为 小7×3
[15:23:30] ⚠ 识别置信度低，跳过帧
```

点某条事件 → 调试模式下可「回放到此状态」。

## 复盘记录

**默认开启**。每局自动存一个 JSON 文件。

### 存哪

`data/replays/YYYYMMDD-HHMMSS-<庄家方向>.json`，例如：

```
data/replays/
├── 20260512-153045-self.json     # 自己庄
├── 20260512-160212-left.json     # 上家庄
└── ...
```

`data/` 目录加进 `.gitignore`（私人复盘数据不入 Git）。

### 不存什么

- **不存录像/截图序列**（硬盘占用大、隐私敏感）
- **例外**：识别置信度低 / 状态机判错那几帧自动存对应截图到 `data/replays/<局>/anomaly/`，作为 bug 追溯证据

### 用途

- 人工复盘：你输了一局，回头看 Mayou 那时推荐什么、你选什么、为什么
- 引擎调参：积累几十局后能统计「Mayou 推荐 vs Max 选择」的分歧分布
- bug 排查：状态机判错时回放到那一帧看 CV 输入

**不是 ML 训练数据**（按 CLAUDE.md 硬约束 4，不接神经网络）。

## 顶栏交互

| 按钮 | 功能 |
|---|---|
| ▶/⏸ 暂停 | 暂停/恢复抓帧识别（离座、被打断时用）。**默认快捷键 Ctrl+Space** |
| ⚙ 设置 | 打开设置面板（透明度、字号、帧率、调试模式、引擎权重等） |
| _ 最小化 | 缩到任务栏 |
| × 关闭 | 退出并保存配置 |

暂停时整个抓帧循环停（不消耗 CPU），事件日志和记牌器冻结。

## 调试模式

⚙ 设置里有「调试模式」开关。打开后右半边底部多一栏「调试」：

- **CV 调试**：最新一帧截图 + 识别框 + 各模板的置信度
- **状态机调试**：完整 `GameState` JSON 实时查看
- **引擎调试**：14 张牌全部分项打分、当前权重 α/β、模拟耗时
- **性能监控**：每层耗时折线图

调试模式只显示，不影响主流程。

## 手动修正

事件日志每条事件右侧有「✎」按钮。点开弹窗：

- 修改家位
- 修改动作类型
- 修改涉及的牌
- 确认后状态机回滚到该事件之前 → 应用修正后的事件 → 之后所有事件按修正重放

修正记录加 `[manual]` 前缀（事件日志里看得见）。

## 设置面板（⚙）

| 项 | 默认值 |
|---|---|
| 主题 | 深色（云手机旁对比清晰） |
| 主字号 | 12px |
| 事件日志字号 | 11px |
| 帧率 | 5fps |
| 暂停热键 | Ctrl+Space ⚠️ 待 Max 确认是否冲突 |
| 显示推荐数 | 2（可改 1/3/全部） |
| 复盘记录 | 开 |
| 调试模式 | 关 |
| 引擎权重 α / β | 0.6 / 0.4（高级） |
| 蒙特卡洛模拟次数 | 1000（高级） |
| 重置适配配置 | 按钮（弹确认） |

## 不做的事

- **不做炫酷动画**
- **不做主题/换肤**（深色一种就够）
- **不做多窗口/多桌同时识别**
- **不做云端同步**（复盘 JSON 在本地）
- **不做任何自动点击/自动出牌**（仅显示建议，Max 手动操作）
- **不做识别 OCR fallback**（模板匹配优先；置信度低就标 ⚠️ 让 Max 修，不引入 OCR 引擎）

## 字号 / 颜色

- 主字号 12px
- 事件日志 11px
- 单色背景：深灰（#1e1e1e 量级）
- 推荐高亮色：亮黄
- 危险色：红 / 橙 / 绿（色盲友好可选 ⚠️ Max 未要求，默认关闭）
- 红色牌（小二/七/十、大贰/柒/拾）在记牌器里用红色字体 + 🔴 标
- 不用图标字体（避免渲染依赖）

## 依赖

- PySide6 ≥ 6.5
- 不引入 QML（QtWidgets 够用）
- 不引入额外 UI 框架（如 Qt Designer 生成代码也不引）

## 验收

- 启动到能用 ≤ 2 秒
- 适配模式下能正确捕捉到红手指窗口区域并显示识别框（Sprint 0 验证）
- 长时间运行（4 小时）无内存泄漏
- 关闭程序后所有设置 + 适配配置自动保存
- 暂停热键工作正常，暂停时 CPU 使用率回到接近 0
