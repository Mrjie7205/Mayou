# ADR-001 · 运行平台选型

- **状态**：✅ Accepted
- **日期**：2026-05-12
- **决策者**：Max
- **影响范围**：整个 CV 层（窗口定位、区域坐标、模板库、识别参数）

## 背景

Mayou 通过截屏来识别棋牌牌局。**平台一旦选定，几乎不能换**——区域坐标、模板库、识别参数全部绑定单一平台。换平台 = 整个 CV 层重做。

初稿设想用 PC 云游戏（网易云 / 腾讯先锋 / 咪咕快游）。但深入想后发现：
- 主流 PC 云游戏平台的游戏库以 3A 为主，棋牌品类稀少且不稳定
- 闲逸棋牌（含株洲碰胡）是手游 App，没有上架到 PC 云游戏平台
- 真正能稳定运行闲逸的方案是**云手机**（远程安卓真机 + PC 客户端）

因此 Sprint -1 期间把候选从「PC 云游戏」族切换为「云手机」族。

## 候选

### A. 红手指云手机（选定）

- 老牌云手机厂商，PC 客户端成熟
- 允许装第三方 APK 包括棋牌类
- 截屏权限：PC 客户端窗口为常规桌面窗口，mss / PrtSc / 截图工具均能正常截取
- 价格：免费时段 + 包时套餐

### B. 多多云手机

- 同类竞品，使用情况较宽松
- 棋牌支持较好
- 备选方案

### C. 雷电云手机

- 雷电模拟器同公司出品
- PC 客户端体验好
- 备选方案

### D. 网易云手机

- 大厂背书，稳定性高
- 但对棋牌类 App 的运行限制较严
- 不优先

### E.（已否决）PC 云游戏（网易云 / 腾讯先锋 / 咪咕快游）

- 游戏库以 3A 为主
- 闲逸棋牌不上架
- 不适合本项目场景

## 决策记录

**选定平台**：**红手指云手机 PC 客户端 + 闲逸棋牌 App**

**理由**：
- 唯一能稳定运行闲逸棋牌的远程方案（PC 云游戏平台没有闲逸）
- 老牌厂商、PC 客户端成熟、截屏兼容性已知良好
- Max 基于先验使用经验直接选定，认为前述硬性条件全部满足；详细 CV 参数延后到 Sprint 0 实测

**验证方式**：基于 Max 对红手指 PC 客户端的先验使用经验。详细 CV 校准延后到 Sprint 0 用实际窗口测量。如 Sprint 0 实测时发现关键阻塞（mss 黑屏、风控立即触发等），则重启本 ADR。

**已知约束**：
- 接受云手机平台被棋牌风控视为黑产高发场景，按 CLAUDE.md 硬约束 5 处理（封号不抗，更换号或停用）
- 仅在闲逸欢乐豆纯娱乐房间使用（CLAUDE.md 硬约束 1）

**重新评估触发条件**：
- 红手指下架闲逸棋牌或全面禁止棋牌类 App
- 红手指改版导致 CV 重建工作量 >2 周
- mss 在 Sprint 0 实测时被证明不可用
- 出现明显更优选项
