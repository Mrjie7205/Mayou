# 05 · UI 规格

> PySide6 悬浮窗，挂在云游戏窗口旁边。
> "够用、能调试"，不追求美观。

## 窗口形态

- **无边框、置顶、半透明背景**（透明度可调）
- 启动后自动定位到云游戏窗口右侧（如果右侧空间不够，就左侧）
- 可拖动，位置记忆到 `assets/configs/<platform>.json`
- 关闭按钮在右上角

## 主面板布局

```
┌─────────────────────────────────┐
│ Mayou  [☰][⚙][_][×]            │  顶栏
├─────────────────────────────────┤
│ ▼ 我的手牌                      │
│ [1筒][2筒][...][9万]  推荐:5筒│
├─────────────────────────────────┤
│ ▼ 剩余牌统计                    │
│ 筒: 1=4 2=2 3=3 4=4 ...          │
│ 条: 1=4 2=4 3=1 4=2 ...          │
│ 万: 1=4 2=3 3=4 4=2 ...          │
├─────────────────────────────────┤
│ ▼ 各家危险牌                    │
│ 上家🟢 对家🟡 下家🔴            │
│ 对家可能在听: 5筒 8筒 9万       │
├─────────────────────────────────┤
│ ▼ 听牌信息（如果自己听了）       │
│ 听: 3条 6条 9条                 │
│ 剩: 7张                         │
│ 胡牌概率: 23%                   │
├─────────────────────────────────┤
│ ▼ 事件日志                      │
│ [15:23:45] 对家打 5筒           │
│ [15:23:42] 下家碰 3条           │
│ [15:23:40] ...                 │
└─────────────────────────────────┘
```

每个区块可折叠，状态记忆。

## 推荐显示

手牌区域，推荐的那张：

- 加亮（边框/底色）
- 旁边显示 `推荐:X筒`
- 鼠标悬停弹小卡片：

```
推荐: 5筒
─────────────
进攻: 0.62
  └ 打后 1向听
  └ 胡牌率 18%
  └ 期望番 2.3
防守: 0.81
  └ 上家危险: 5%
  └ 对家危险: 32%
  └ 下家危险: 12%
综合: 0.71
```

## 危险牌可视化

每家用 🟢/🟡/🔴 三档总体安全等级。点开看具体危险牌：

```
对家 🟡 中等危险
  高危: 5筒(80%) 8筒(75%)
  中危: 9万(45%)
  低危: 其他
```

颜色阈值（可调）：
- 🟢 整体危险度 <0.2
- 🟡 0.2-0.5
- 🔴 >0.5

## 事件日志

最近 20 条事件，最新在上。每条带时间戳。

格式：
- `[时间] 家位 动作 牌` (e.g., `[15:23:45] 对家 打 5筒`)
- 手动修正：`[15:23:47] [manual] 状态修正: 下家碰组改为 3条×3`
- 异常：`[15:23:50] ⚠ 识别置信度低，跳过`

点击某条事件可以"回放到那个状态"（调试用）。

## 调试模式开关

⚙ 按钮打开调试面板，含：

- **CV 调试**：最新一帧截图 + 识别框 + 置信度
- **状态机调试**：完整 GameState JSON 实时查看
- **引擎调试**：各张牌的分项打分、当前权重、模拟耗时
- **性能监控**：每层耗时图

调试模式只显示，不影响主流程。

## 手动修正

事件日志区，每条事件右侧有"✎ 修正"按钮。点开弹窗：

- 修改家位
- 修改动作类型
- 修改涉及的牌
- 确认后状态机回滚到该事件之前 → 重新应用修正后的事件 → 之后所有事件重放

修正记录加 `[manual]` 前缀。

## 全局设置

⚙ 设置面板：

- 透明度
- 字号
- 自动定位
- 帧率（默认 5fps，可调 3-10）
- 调试模式开关
- 引擎权重 α、β（高级）
- 蒙特卡洛模拟次数（高级）
- 重置区域配置（重新框选）

## 不做的事

- **不做炫酷动画**
- **不做主题/换肤**
- **不做多窗口/多桌**
- **不做云端同步**
- **不做任何自动点击操作**

## 字号 / 颜色

- 主字号 12px，事件日志 11px
- 单色背景（深色，便于云游戏旁边对比）
- 推荐高亮色：亮黄
- 危险色：红 / 橙 / 绿
- 不用图标字体（避免渲染依赖）

## 依赖

- PySide6 ≥ 6.5
- 不引入 QML（用 QtWidgets 就够）
- 不引入额外 UI 框架

## 验收

- 启动到能用 ≤2 秒
- 拖动、折叠、设置都流畅
- 长时间运行（4 小时）无内存泄漏
- 关闭程序后配置自动保存
