# 06 · 转转麻将规则速查

> 引擎实现的唯一规则依据。来源：黄金岛转转麻将官方规则（[原文](https://www.80166.com/guide/rule/zzmj.html)）。
> 如果云游戏平台采用的转转规则与本文档有出入，**以平台为准**，并在本文档加变体说明。

## 1. 牌张

**108 张牌**：
- 1-9 筒 × 4 = 36 张
- 1-9 索（条） × 4 = 36 张
- 1-9 万 × 4 = 36 张

**没有**：东南西北风、中发白、花牌、红中、赖子、任何字牌。

⚠️ 转转麻将和很多带红中赖子的玩法（武汉麻将、红中赖子杠、红中麻将）**不是一回事**。引擎实现时绝对不要混淆。

## 2. 起手

- 庄家 14 张，闲家各 13 张
- 庄家先打第一张

## 3. 行牌动作

| 动作 | 转转麻将 | 说明 |
|---|---|---|
| 摸牌 | ✅ | |
| 打牌 | ✅ | |
| **吃** | ❌ | **无吃牌**，这是转转麻将的核心特征 |
| 碰 | ✅ | 别家打的牌 + 自己手里 2 张 |
| 明杠 | ✅ | 碰过的牌再摸到第 4 张 |
| 暗杠 | ✅ | 手里 4 张相同 |
| 加杠 | ✅ | 同明杠（碰后摸第 4 张） |
| 抢杠胡 | ✅ | 明杠/加杠时被胡，暗杠不可抢 |

⚠️ **"无吃牌"对引擎影响巨大**：

- 顺子只能靠摸牌自然形成
- 副露区只会有碰、杠两种，没有"吃"组
- 大部分日麻 AI / 国标 AI 默认有吃，**必须改造**

## 4. 胡牌牌型

### 4.1 基础牌型

**4 副面子 + 1 对将** = 胡牌。共 14 张。

- 面子 = 顺子（同花色相邻 3 张）或 刻子（3 张相同）
- 将 = 对子
- **乱将**：任何对子都能做将（不像有些规则只能 2/5/8 做将）

### 4.2 大胡牌型（特殊牌型）

转转麻将不区分大小胡（"不区分大小胡"），但有特殊牌型加番：

| 牌型 | 说明 |
|---|---|
| 清一色 | 筒、索、万三色任选其一，整副牌只有一色 |
| 碰碰胡 | 4 副刻子（或杠）+ 1 对将，全部碰出来 |
| 七巧对 | 7 个对子 |
| 将将胡 | 全部由 2/5/8 组成 |
| 全求人 | 全靠碰/杠/捉炮形成的牌 |

转转麻将基础胡更宽松，特殊牌型作为加番项。具体平台可能有变体，**实测确认**。

## 5. 胡牌方式

- **自摸**：自己摸到胡牌张
- **点炮（捉炮）**：胡别家打出的牌
- **抢杠胡**：胡别家明杠/加杠的那张
- **海底**：胡最后一张

转转麻将不区分庄家闲家在小胡上的分差太多（"不区分大小胡"，但有些计分细则差异）。

## 6. 番数与计分概览

引擎层只需要算番数大小，具体筹码换算 UI 显示即可。

### 6.1 基础番数（黄金岛规则）

- 平胡基础 1 番
- 自摸 +1 番
- 每个一根筋（杠）+1 番，可累加
- 海底胡 加番（具体看平台）
- 杠上花 加番
- 碰碰胡、清一色、七巧对等特殊牌型有独立番数

### 6.2 一根筋

**任何杠**（明杠、暗杠、加杠）= 一根筋 = +1 番。多个杠累加。

### 6.3 扎鸟（与引擎无关）

胡牌后从牌墙翻一张/几张，看落在哪家头上，决定额外赔付倍数。完全随机，**引擎不参与计算**，但 UI 可以显示结果。

## 7. 对引擎实现的具体影响

| 规则差异 | 引擎要做的事 |
|---|---|
| 无吃 | shanten 计算时**禁用顺子组合的"吃"产生路径**；只允许"摸到顺子的中间张自然成顺" |
| 无字牌 | shanten 表只覆盖 27 种序数牌（筒索万 1-9） |
| 无赖子 | 完全标准的牌型枚举，无万能牌处理 |
| 乱将 | 任意对子可做将 |
| 不区分大小胡 | 番数计算后直接 × 基础分，无大胡阈值 |
| 起手胡 | 平台是否启用要确认 |
| 杠 = 一根筋 | 番数 +1 |

## 8. 不确定/平台变体

以下规则在不同平台/房间有差异，**对接云游戏时需要实测确认**，写入 `assets/configs/<platform>.json` 的 `rule_variant` 字段：

- 起手胡是否启用、有哪些牌型
- 是否允许"过水"（即过手后能否再胡）
- 流局是否退分
- 一炮多响是否允许
- 杠后是否必须打一张才能继续
- 听牌后能否改听（一般禁止）
- 番数的具体倍率

每条变体在配置里有开关，引擎根据配置切换。

## 9. 引擎单元测试必覆盖的局面

- 1 万、2 万、3 万 + 4 万、5 万、6 万 + 7 索、8 索、9 索 + 红5、红5、红5 + 9 筒、9 筒：胡（4 顺 + 1 将）
- 7 个对子：胡（七巧对）
- 同花色 14 张组成 4 面子 + 将：胡（清一色 + 平胡）
- 缺一张听牌：shanten = 0
- 听单钓将
- 听双碰
- 听两面（如 2、3 听 1/4）
- 听坎张（如 1、3 听 2）
- 听边张（如 1、2 听 3 / 8、9 听 7）
